# NLP Text Processing Notebook

A Jupyter notebook that works through basic NLP techniques on short example sentences.

## Features

- Tokenization and stop-word removal with NLTK
- Part-of-speech (POS) tagging with `nltk.pos_tag`
- Bag of words with scikit-learn's `CountVectorizer`
- TF-IDF computed by hand (term frequency and IDF functions)
- N-grams
- Visualisation with seaborn

## Tech stack

Python, Jupyter Notebook, NLTK, scikit-learn, pandas, NumPy, seaborn, matplotlib

## Getting started

```bash
git clone https://github.com/Matiz009/nlp-text-processing-notebook.git
```
